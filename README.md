# Y Master Editor — Simple Folder Guide

Welcome! This project folder is organized from the **oldest version (1)** to the **newest version (3)**:

## Folder Structure

* **`Install Y Master Editor (Latest).exe`**
  * Double-click this file to install the newest version (**Y Master Editor v3.0**) on your computer.
* **`1. Oldest Version - PDF Studio (v1.0)/`**
  * `Install PDF Studio (v1.0).exe` — Installer for the original version.
  * `PDF Studio Portable (v1.0).exe` — Run directly without installing.
  * `App Code/` — Source files for v1.0.
* **`2. Second Version - Foliyo (v2.0)/`**
  * `Install Foliyo (v2.0).exe` — Installer for the second version (**Foliyo** redesign).
  * `Foliyo Portable (v2.0).exe` — Run directly without installing.
  * `App Code/` — Source files for v2.0.
* **`3. Newest Version - Y Master Editor (v3.0)/`**
  * `Install Y Master Editor (v3.0).exe` — Installer for the newest version (**Y Master Editor** with minimalist **Y** logo, Light Earth Tone UI, and Google/Firebase Sign-In).
  * `Y Master Editor Portable (v3.0).exe` — Run directly without installing.
  * `App Code/` — Source files for v3.0.
* **`Product_Briefing_Document.pdf`**
  * Exported vector Product Briefing PDF document.
